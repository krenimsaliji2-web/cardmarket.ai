# Project Atlas

# Artificial Intelligence Specification

Version: 1.0

Status: Draft

---

# Purpose

Dieses Dokument definiert alle KI-Funktionen der Plattform.

Die KI soll den Benutzern helfen, Karten schneller zu erkennen, Inserate einfacher zu erstellen und bessere Kauf- und Verkaufsentscheidungen zu treffen.

---

# AI Principles

Die KI unterstützt den Benutzer.

Sie trifft niemals endgültige Entscheidungen.

Der Benutzer kann alle Vorschläge bearbeiten.

---

# AI Modules

Die Plattform besteht aus mehreren KI-Modulen.

- Card Recognition
- OCR
- Condition Detection
- Price Recommendation
- Image Enhancement
- Fake Detection
- Smart Search
- Listing Assistant
- Portfolio Insights

---

# Card Recognition

Der Benutzer kann:

- Foto aufnehmen
- Bild hochladen

Die KI erkennt:

- Spiel
- Kartenname
- Set
- Kartennummer
- Variante
- Sprache

Anschließend wird automatisch die passende Karte ausgewählt.

---

# OCR

Die KI liest automatisch:

- Kartennamen
- HP
- Kartennummer
- Angriffe
- Beschreibung

Der Benutzer muss nichts eintippen.

---

# Condition Detection

Die KI schätzt den Zustand.

Mögliche Ergebnisse:

- Mint
- Near Mint
- Excellent
- Good
- Played
- Poor

Zusätzlich wird ein Vertrauenswert (Confidence Score) angezeigt.

---

# Price Recommendation

Die KI analysiert:

- aktuelle Angebote
- historische Verkäufe
- Preisentwicklung
- Kartenzustand
- Sprache
- Grading

Ergebnis:

- empfohlener Verkaufspreis
- empfohlener Kaufpreis
- Preisspanne

---

# Image Enhancement

Automatisch:

- Hintergrund verbessern
- Helligkeit anpassen
- Kontrast optimieren
- Bild zuschneiden
- Bild drehen

Originalbild bleibt erhalten.

---

# Listing Assistant

Beim Inserat erstellt die KI automatisch:

- Titel
- Beschreibung
- Kategorie
- Tags
- Preisvorschlag

Der Benutzer kann alles bearbeiten.

---

# Smart Search

Die Suche versteht:

"Glurak PSA 10"

"Pokemon Karte unter 100 CHF"

"Charizard Base Set"

"Yu-Gi-Oh Ghost Rare"

Die KI interpretiert die Suchanfrage.

---

# Fake Detection

Die KI kann verdächtige Karten markieren.

Mögliche Hinweise:

- ungewöhnliche Farben
- falscher Druck
- untypische Schrift
- auffällige Bildqualität

Wichtig:

Die KI liefert nur Hinweise.

Keine endgültige Entscheidung.

---

# Portfolio Insights

Die KI erstellt Analysen:

- Wertentwicklung
- stärkste Gewinner
- stärkste Verlierer
- Risikoverteilung
- Sammlung nach Spielen

---

# AI Notifications

Benachrichtigungen bei:

- Preisänderungen
- neue Angebote
- interessante Auktionen
- Markttrends

---

# Confidence Score

Jedes KI-Ergebnis erhält einen Wert:

0–100 %

Beispiel:

Kartenerkennung

98 %

Preisvorschlag

91 %

Zustandsanalyse

87 %

---

# AI History

Alle KI-Analysen werden gespeichert.

Benutzer können frühere Scans erneut öffnen.

---

# Privacy

Benutzerbilder werden ausschließlich für die Analyse verwendet.

Löschung ist jederzeit möglich.

---

# Performance Goals

Kartenerkennung:

< 5 Sekunden

OCR:

< 3 Sekunden

Preisvorschlag:

< 2 Sekunden

---

# Future Features

Geplant:

- Deck Builder
- Kartentausch-Empfehlungen
- KI-Chat für Sammler
- automatische Sammlungsbewertung
- Marktprognosen
- Scanner für mehrere Karten gleichzeitig

---

# Definition of Done

Das KI-Modul gilt als abgeschlossen, wenn:

✓ Karten erkannt werden

✓ OCR funktioniert

✓ Zustandsanalyse funktioniert

✓ Preisvorschläge erstellt werden

✓ Bilder verbessert werden

✓ KI-Historie verfügbar ist

✓ Datenschutz eingehalten wird

✓ Tests erfolgreich sind
