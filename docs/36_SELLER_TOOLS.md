# Project Atlas

# Seller Tools Specification

Version: 1.0

Status: Draft

---

# Purpose

Dieses Dokument definiert alle Werkzeuge für professionelle Verkäufer und Händler.

Das Ziel ist es, große Kartenbestände effizient verwalten und verkaufen zu können.

Die Plattform unterstützt sowohl private Verkäufer als auch professionelle Händler.

---

# Goals

Die Seller Tools sollen:

- Zeit sparen
- Massenbearbeitung ermöglichen
- Lagerverwaltung vereinfachen
- Verkaufsprozesse automatisieren
- Händler professionell unterstützen

---

# Seller Dashboard

Das Dashboard zeigt:

- Aktive Inserate
- Verkäufe heute
- Verkäufe diesen Monat
- Umsatz
- Offene Bestellungen
- Zu versendende Bestellungen
- Niedrigen Lagerbestand
- Bewertungen

---

# Bulk Listing

Verkäufer können:

- Mehrere Karten gleichzeitig einstellen
- Mehrere Bilder hochladen
- Preise gleichzeitig festlegen
- Kategorien automatisch übernehmen

---

# CSV Import

Unterstützte Formate:

- CSV
- XLSX

Importiert werden können:

- Karten
- Preise
- Zustände
- Mengen
- Sprache
- Varianten

Nach dem Import erfolgt eine Vorschau mit Fehlerprüfung.

---

# Bulk Editing

Mehrere Inserate können gleichzeitig geändert werden.

Beispiele:

- Preis ändern
- Zustand ändern
- Versandkosten ändern
- Bestand ändern
- Inserate pausieren
- Inserate aktivieren

---

# Inventory Management

Verkäufer verwalten:

- Lagerbestand
- Mengen
- Lagerorte
- Mindestbestand

Bestände werden nach Verkäufen automatisch aktualisiert.

# Inventory Alerts

Benachrichtigungen bei:

- Fehlerhaften Beständen
